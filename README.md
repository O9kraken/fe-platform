# ZERO/STACK — веб-разработка с нуля

Курс с тремя направлениями: **Frontend**, **Backend** и **Fullstack**. Редактор кода с автотестами, тренажёры SQL и API прямо в браузере, песочница и наставник. Аккаунты и прогресс хранятся в PostgreSQL (Neon), код лежит на GitHub, сайт работает на Render.

## Направления

| Направление | Недель | Что внутри |
|---|---|---|
| Frontend | 30 | HTML, CSS, JavaScript, TypeScript, React, Next.js, тесты, производительность |
| Backend | 31 | Терминал, JavaScript, TypeScript, Node.js, HTTP и REST, Express, SQL, PostgreSQL, ORM, авторизация, безопасность, тесты API, архитектура, Redis, WebSocket, Docker, деплой |
| Fullstack | 40 | Фронтенд до Next.js + бэкенд до деплоя + связка фронта и бэка и финальный проект |

Общие уроки (основа, JavaScript, TypeScript, SQL) засчитываются во всех направлениях: ученик может сменить направление без потери прогресса. Темп — 8–12 часов в неделю.

## Адреса

| Адрес | Что там |
|---|---|
| `/` | Лендинг: направления, устройство урока, лаборатория, схемы, мотивация, наставник, программа по неделям, вопросы. Если ученик вошёл, в шапке и первом экране видно его аккаунт: уровень, XP за сегодня, серия дней, решённые задачи, процент курса и следующий урок |
| `/app` | Сама платформа (вход и регистрация — тут же). `/app?mode=register` открывает регистрацию |
| `/app#w12`, `/app#today`, `/app#cards`, `/app#gloss`, `/app#admin` | Сразу нужная неделя или раздел |
| любой другой адрес | Страница 404 со ссылками на платформу, программу и словарь (`public/404.html`); для `/api/...` — JSON-ошибка |
| `/robots.txt`, `/og.png` | Поисковикам открыт только лендинг; картинка-превью для ссылок в мессенджерах |

Сводку для лендинга платформа сохраняет сама в документ `summary` при каждом изменении прогресса.

## Что внутри

- **Оформление** — тёмная тема: чёрный фон, красное свечение, лаймовый акцент, тонкие заглавные заголовки (Unbounded), цифры точечным шрифтом (Doto).
- **Подробные уроки** — к каждому из 306 пунктов «Что изучить», по методикам науки об обучении. Семь разделов: «Ситуация» (живая задача-завязка), «На пальцах», «Как это работает», «Пример», «Частые ошибки», «Проверь себя», «Мини-задание». Открываются кнопкой «Разобрать» без наставника. Лежат в `public/lessons/<id-урока>.md`, каждый пункт начинается строкой `@@ номер`.
- **Вопросы с открытым ответом** внутри уроков — строки `?? вопрос || ответ` («Вспомни»), `?! вопрос || ответ` («Предскажи» результат кода) и `?: вопрос || ответ` («Почему так?»). Рендерятся раскрывающимися карточками: сначала ответь сам, потом открой. Вопрос и ответ делит первый `||` вне обратных кавычек.
- **Графика в разборах** (`public/js/lesson-art.js`) — у каждого разбора шапка с тематической иллюстрацией (19 анимированных SVG по темам: сеть, терминал, HTML, CSS, JS, React, базы, безопасность, Docker и др.), навигация по разделам, картинка к аналогии «На пальцах», шаги лесенкой, ошибки карточками. Строка `>> Шаг → Шаг → Шаг` в уроке рисуется схемой-цепочкой; такая схема есть в каждом из 306 разборов.
- **Телефон** — поля ввода 16px (iOS не приближает экран при фокусе), пальцевые цели от 40px, таблицы из 3+ колонок превращаются в карточки, компактные «Сегодня» и «Практика», в редакторе — панель символов `{ } ( ) ; =>…` над клавиатурой и перенос длинных строк, лаборатория подстраивается под открытую клавиатуру.
- **«Как учиться»** — шесть приёмов (повторение с паузами, вспоминание, чередование, «почему», конкретные примеры, слова + схемы), PRIMM для кода и объяснение своими словами — с привязкой к разделам платформы и источниками.
- **Тесты** — по 4 вопроса с разбором к каждому уроку, 220 вопросов. Дополнительные лежат в `public/js/quiz-extra.js`.
- **Конспекты** — к каждому из 55 уроков: ключевые идеи, рабочие примеры кода и «Запомни». Лежат в `public/notes/*.md`, их легко дополнять: каждый урок начинается строкой `@@ id-урока`.
- **Словарь разработчика** — 158 терминов, которые звучат в командах и на собеседованиях («стек», «деплой», «мерж», «эндпоинт», «CI/CD»…): простое объяснение, пример из жизни, другие названия и у 27 — готовый ответ для интервью. Поиск, категории, фильтр «только с ответом». Термины попадают в поиск и в карточки повторения. Лежат в `public/js/terms.js`.
- **Поиск** — Ctrl + K или «/»: уроки, разделы конспектов, задачи, схемы и термины.

- **Интерфейс** — боковое меню с разделами «Учёба», «Инструменты», «Карьера»; на телефоне — нижняя панель. Урок открывается на всю ширину, сверху — переключатель недель, карта всех недель и быстрые переходы к разделам урока с отметками «готово». Новичка встречает короткое знакомство: выбор направления, цели дня и обзор разделов.

- **Сегодня** — главный экран: следующий шаг, цель дня в XP, активность за неделю, серия дней, карта пути по всем неделям, достижения.
- **Интерактивные схемы** — 15 живых объяснений к ключевым темам: путь запроса, Git-ветки, специфичность CSS, блочная модель, flexbox-тренажёр, grid, map/filter/reduce, event loop по шагам, рендер React и memo, сборка HTTP-запроса, цепочка middleware, JOIN, индексы, устройство JWT с подделкой подписи, кеш и TTL.
- **Игровые механики** — уровни и XP, дневная цель, учебные дни недели (в дни отдыха серия не сгорает), серия дней, 19 достижений, конфетти за решённые задачи и закрытые недели.
- **Повторение** — карточки по системе Лейтнера: термины словаря и вопросы пройденных недель, до 10 новых в день.

## Практика в браузере

| Режим | Как работает |
|---|---|
| HTML · CSS · JS | Живое превью в изолированном iframe, тесты проверяют DOM и стили |
| JavaScript, TypeScript | Консоль; TypeScript компилируется Babel |
| React | React 18 и JSX без сборки |
| Node API | Симуляция Express в браузере: тот же код маршрутов и middleware, панель для отправки запросов, тесты шлют настоящие HTTP-подобные запросы |
| SQL | SQLite (sql.js) с базой студии: клиенты, проекты, платежи. Результат ученика сравнивается с эталонным запросом |

75 встроенных задач с автопроверкой, подсказками и эталонами. Наставник может сгенерировать новую задачу по теме недели и сам проверит её тесты эталонным решением.

```
Браузер ──► Render (Node.js + Express) ──► Neon (PostgreSQL)
                     │
                     └──► Anthropic API (наставник, по желанию)
GitHub ──push──► Render пересобирает сайт автоматически
```

## Запуск в интернете: 3 шага

### 1. Neon — база данных
1. Зарегистрируйся на [neon.tech](https://neon.tech) и создай проект (регион — Frankfurt, ближе к Render).
2. На главной проекта нажми **Connect** и скопируй строку подключения. Она выглядит как `postgresql://…neon.tech/neondb?sslmode=require`.
3. Таблицы создавать не нужно: сервер сделает это сам при первом запуске.

### 2. GitHub — код
```bash
cd fe-platform
git remote add origin https://github.com/ТВОЙ_ЛОГИН/frontend-course.git
git push -u origin main
```
Репозиторий можно сделать приватным: Render всё равно его увидит после подключения GitHub-аккаунта.

### 3. Render — сайт
1. Зайди на [render.com](https://render.com) через GitHub.
2. **New → Blueprint**, выбери репозиторий. Render прочитает `render.yaml`.
3. Заполни переменные, которые он попросит:
   - `DATABASE_URL` — строка из Neon;
   - `ADMIN_PASSWORD` — пароль для аккаунта **KRAKER** (минимум 8 символов);
   - `GIGACHAT_AUTH_KEY` — ключ авторизации GigaChat API (бесплатно для физлиц, [developers.sber.ru/studio](https://developers.sber.ru/studio)), если нужен наставник. Без ключа всё остальное работает.
4. Нажми **Apply**. Через 2–3 минуты сайт откроется по адресу вида `https://frontend-course.onrender.com`.
5. Войди как `KRAKER` с паролем из шага 3.

После этого каждый `git push` в ветку `main` автоматически обновляет сайт.

## Переменные окружения

| Переменная | Обязательна | Что делает |
|---|---|---|
| `DATABASE_URL` | да | Строка подключения к Neon |
| `JWT_SECRET` | да | Секрет для подписи сессий. Render генерирует сам |
| `ADMIN_USERNAME` | нет | Логин администратора, по умолчанию `KRAKER` |
| `ADMIN_PASSWORD` | при первом запуске | Пароль админа. Нужен только чтобы создать аккаунт |
| `GIGACHAT_AUTH_KEY` | нет | Наставник на GigaChat (Сбер). Основной бесплатный вариант |
| `GIGACHAT_MODEL` | нет | Первая модель, по умолчанию `GigaChat-3-Ultra`; дальше сами: `GigaChat-2-Max` → `GigaChat-2-Pro` → `GigaChat-2` |
| `DEEPSEEK_API_KEY` | нет | DeepSeek (`DEEPSEEK_MODEL`, по умолчанию `deepseek-flash`) — запасной или основной вариант |
| `GROQ_API_KEY` / `OPENROUTER_API_KEY` | нет | Бесплатные лимиты Groq или OpenRouter (`GROQ_MODEL`, `OPENROUTER_MODEL`) |
| `AI_API_KEY` + `AI_BASE_URL` + `AI_MODEL` | нет | Любой OpenAI-совместимый API |
| `ANTHROPIC_API_KEY` | нет | Claude (`ANTHROPIC_MODEL`, по умолчанию `claude-sonnet-5-5`) |
| `AI_PROVIDER` | нет | Порядок провайдеров, например `deepseek,gigachat`. Если задано несколько ключей — первый основной, остальные запасные |
| `AI_DAILY_LIMIT` | нет | Вопросов наставнику в день на ученика, по умолчанию 30. У админа без лимита |
| `AI_GLOBAL_DAILY_LIMIT` | нет | Вопросов в день на всю платформу, по умолчанию 500 — бережёт бесплатную квоту |
| `AI_TEMPERATURE` | нет | По умолчанию 0.2: меньше фантазий, точнее ответы |
| `ALLOW_REGISTRATION` | нет | `false` — закрыть регистрацию, новых учеников заводит админ |

## Администратор KRAKER

- Создаётся автоматически при первом запуске, если задан `ADMIN_PASSWORD`. Если KRAKER уже есть, пароль из переменной не перезаписывает текущий.
- Логин KRAKER зарезервирован: зарегистрироваться под ним никто не сможет.
- Вкладка **«Ученики»** видна только админам: направление и прогресс каждого, решённые задачи, задачи с тремя и более неудачными попытками, дневник, вопросы наставнику за неделю.
- Действия с учеником: сбросить пароль (выдаётся временный), сделать админом, заблокировать, удалить.
- Себя заблокировать или лишить прав нельзя, чтобы случайно не остаться без админа.

## Локальный запуск

Нужен Node.js 20+.
```bash
npm install
cp .env.example .env   # впиши DATABASE_URL, JWT_SECRET, ADMIN_PASSWORD
npm run dev            # http://localhost:3000
```
Для локальной разработки удобно создать в Neon отдельную ветку базы (Branches → Create branch) и взять её строку подключения.

## Безопасность

- Пароли хранятся только в виде bcrypt-хеша.
- Сессия — httpOnly-cookie на 30 дней, `SameSite=Lax`, `Secure` в продакшене.
- Изменяющие запросы принимаются только как JSON, что вместе с `SameSite` защищает от CSRF.
- 10 неудачных входов за 15 минут — временная блокировка попыток.
- Смена пароля, сброс или блокировка выкидывают аккаунт со всех устройств.
- Код учеников выполняется в изолированном iframe (`sandbox` без `allow-same-origin`): он не видит cookie и данные сайта.

## Что учесть

- Бесплатный тариф Render засыпает через 15 минут без посещений. Первое открытие после сна занимает около 30–50 секунд. Тариф Starter убирает сон.
- Бесплатный Neon тоже засыпает, но просыпается за секунду. Сервер к этому готов.
- Состояние наставника видно в админке («Ученики» → блок «Наставник»): какие нейросети подключены, сколько вопросов задано сегодня, кнопка «Проверить ответ».
- GigaChat требует сертификат НУЦ Минцифры. Сервер скачивает его сам при первом запросе; можно положить файл в `server/certs/russian_trusted_root_ca.pem`.
