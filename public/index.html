02 / Направления

Выбери свой путь.

Три маршрута с одной основой. Общие уроки засчитываются везде, поэтому направление можно сменить в любой момент, и прогресс не пропадёт.

03 / Как устроен урок

Одна неделя — одна тема.

Каждый урок собран по одной схеме: сначала понять, потом потрогать руками, потом закрепить. Прогресс по каждому шагу отмечается и виден на карте курса.

Главные идеи, рабочие примеры кода и блок «Запомни». Можно вернуться в любой момент.

04 / Лаборатория

Пишешь код — тесты отвечают сразу.

Полноценный редактор с подсветкой и автодополнением скобок. Ничего не нужно устанавливать: код выполняется в изолированной песочнице браузера.

  • HTML · CSS · JSживое превью, тесты проверяют разметку и стили
  • JS · TSконсоль, TypeScript компилируется на лету
  • REACTReact 18 и JSX без сборки
  • NODE APIExpress в браузере: маршруты, middleware и панель запросов
  • SQLнастоящая база студии: клиенты, проекты, платежи

Застрял — открой подсказку, спроси наставника или посмотри эталон. Наставник может придумать новую задачу по теме, а платформа сама проверит её тесты эталонным решением.

    07 / Наставник

    Наставник, который не устаёт от вопросов.

    Встроен в каждый урок и в лабораторию. Видит задачу и твой код, поэтому отвечает по делу, а не общими словами.

    • Разбирает любую тему недели простыми словами
    • Объясняет, почему не проходит тест, и не выдаёт ответ сразу
    • Придумывает новые задачи по теме — с тестами и эталоном
    • Проверяет дневник и подсказывает, что повторить
    Почему map вернул массив из undefined?
    НаставникПредставь конвейер: на ленту кладут яйца, а курица на каждом шаге должна положить обратно что-то новое. Если она ничего не положила — на ленте пусто, то есть undefined.

    Внутри фигурных скобок нужен return:
    arr.map(x => { return x * 2; })
arr.map(x => x * 2) // или без скобок

    10 / Вопросы

    Частые вопросы.

    Я вообще ничего не знаю о программировании. Мне подойдёт?

    Да, курс рассчитан именно на старт с нуля. Первая неделя объясняет, как устроен интернет и что происходит, когда открываешь сайт. Каждая тема сначала объясняется простыми словами, а уже потом — терминами.

    Что нужно установить?

    Чтобы начать — ничего: уроки, редактор и тесты работают в браузере. По ходу курса ты сам установишь VS Code, Node.js и Git — для этого есть отдельные уроки с пошаговыми инструкциями.

    Какое направление выбрать?

    Нравится делать то, что видно на экране, — Frontend. Интересно, как устроены данные, серверы и базы — Backend. Хочешь уметь сделать сервис целиком — Fullstack, он длиннее, зато полный. Сомневаешься — начни с Fullstack: первые недели у всех направлений общие.

    Можно сменить направление потом?

    Да, в настройках аккаунта. Общие уроки — основа, JavaScript, TypeScript, SQL — засчитываются во всех направлениях, поэтому пройденное не потеряется.

    Сколько времени это займёт?

    Frontend — 30 недель, Backend — 31, Fullstack — 40 при темпе 8–12 часов в неделю. Цель на день можно выбрать от 25 минут до двух часов.

    Как проверяются задачи?

    У каждой задачи есть автотесты: они запускают твой код, проверяют разметку, стили, ответы сервера или результат SQL-запроса. Если что-то не так, видно, какой именно тест упал и почему.

    Что делать, если не понимаю тему?

    Нажми «Разобрать» рядом с темой — придёт подробное объяснение с примерами. Можно задать вопрос наставнику своими словами, перечитать конспект или открыть схему.

    Хватит ли этого, чтобы найти работу?

    В конце каждого направления есть раздел «Готов к работе?»: чек-лист навыков, которые спрашивают на собеседованиях, и подходящие вакансии. Плюс два-три проекта в портфолио, сделанные по ходу курса.
