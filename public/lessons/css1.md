### На пальцах
HTML — это голые стены и мебель, CSS — ремонт: цвет стен, обои, расстановка. Держать стили в отдельном файле — как иметь один дизайн-проект на весь дом: поменял цвет в одном месте — изменились все комнаты.

### Как это работает
Есть три способа подключить стили:

| Способ | Как | Когда |
|---|---|---|
| Внешний файл | `<link rel="stylesheet" href="css/style.css">` в `head` | почти всегда |
| Тег style | `<style> ... </style>` в `head` | быстрые эксперименты |
| Атрибут style | `<p style="color: red">` | почти никогда |

Внешний файл лучше всего: один файл на все страницы, браузер кеширует его и не скачивает повторно, HTML остаётся чистым.

CSS-правило состоит из селектора и блока объявлений:

```css
селектор {
  свойство: значение;
  свойство: значение;
}
```

### Пример
```html
<!-- index.html -->
<head>
  <meta charset="utf-8">
  <title>Студия</title>
  <link rel="stylesheet" href="css/style.css">
</head>
```

```css
/* css/style.css */
body {
  font-family: system-ui, sans-serif;
  color: #1e2a36;
  background: #f6f7f9;
  margin: 0;
}

h1 {
  font-size: 40px;
  color: #1f4fd8;
}
```

### Частые ошибки
- Неверный путь в `href` — стили просто не применятся. Проверь вкладку Network: файл с кодом 404.
- Забыть точку с запятой между объявлениями — следующее свойство сломается.
- Стили в атрибутах `style` по всей странице — их невозможно поддерживать.

### Мини-задание
Создай `css/style.css` и подключи его к двум своим страницам. Задай шрифт, цвет текста и фона для `body` и цвет для `h1`. Поменяй цвет в одном месте и убедись, что он поменялся на обеих страницах.

### На пальцах
Селектор — это адресат приказа. «Всем сотрудникам» — селектор по тегу. «Всем из отдела продаж» — по классу. «Ивану Петрову лично» — по id. «Всем, кто сидит в переговорной» — селектор потомка. «Тому, на кого навели указку» — `:hover`.

### Как это работает
| Селектор | Пример | Кого выберет |
|---|---|---|
| тег | `p` | все абзацы |
| класс | `.card` | все элементы с `class="card"` |
| id | `#header` | один элемент с `id="header"` |
| потомок | `.menu a` | все ссылки внутри `.menu` на любой глубине |
| дочерний | `.menu > li` | только прямые дети |
| несколько | `h1, h2` | и те, и другие |
| псевдокласс | `a:hover` | ссылку под курсором |

Другие полезные псевдоклассы: `:focus-visible` (фокус с клавиатуры), `:first-child`, `:last-child`, `:nth-child(2n)` (каждый второй), `:disabled`, `:checked`.

На практике стилизуют в основном через классы: они переиспользуются и имеют предсказуемый вес. id в CSS лучше не использовать — у него слишком большой вес, и потом его трудно перебить.

У элемента может быть несколько классов через пробел: `class="btn btn--primary"`.

### Пример
```css
.card {
  padding: 16px;
  border: 1px solid #d3dae1;
  border-radius: 12px;
}

.card h3 {
  margin-top: 0;
}

.btn {
  background: #1f4fd8;
  color: white;
}

.btn:hover {
  background: #1a43b8;
}

.list li:nth-child(odd) {
  background: #f1f4f7;
}
```

### Частые ошибки
- Забыть точку перед классом: `card { }` ищет тег `<card>`.
- Писать в HTML `class=".card"` с точкой.
- Слишком длинные селекторы: `body main section div ul li a` — хрупко и сложно перебить.

### Мини-задание
Свёрстай три карточки услуг с классом `card` и кнопкой `btn` в каждой. Сделай эффект при наведении на кнопку и раскрась каждую вторую карточку другим фоном через `:nth-child`.

### На пальцах
Каскад — порядок старшинства приказов. Если начальник отдела сказал «красный», а директор лично тебе — «синий», победит директор (специфичность). Если два одинаково важных приказа противоречат — действует последний (порядок). Наследование — как фамилия: цвет текста передаётся от родителя детям сам.

### Как это работает
Когда к элементу применяются противоречащие правила, браузер решает так:

1. **Важность**: `!important` побеждает всё. Пользоваться почти никогда не нужно.
2. **Специфичность** — «вес» селектора, три числа: сколько id, сколько классов, сколько тегов.
3. **Порядок**: при равном весе побеждает правило, написанное ниже.

| Селектор | Вес |
|---|---|
| `p` | 0-0-1 |
| `.card p` | 0-1-1 |
| `.card .title` | 0-2-0 |
| `#main .title` | 1-1-0 |

Веса сравнивают слева направо: один id тяжелее любого количества классов.

Наследование: свойства текста (`color`, `font-family`, `font-size`, `line-height`) передаются детям. Свойства коробки (`margin`, `padding`, `border`, `background`) — нет. Поэтому шрифт и цвет удобно задать один раз у `body`.

В DevTools → Elements → Styles видно все правила элемента. Перечёркнутые — те, что проиграли.

### Пример
```html
<p class="note" id="first">Кто победит?</p>
```

```css
p { color: black; }          /* 0-0-1 */
.note { color: green; }      /* 0-1-0 — сильнее тега */
#first { color: red; }       /* 1-0-0 — сильнее класса, текст красный */
.note { color: blue; }       /* 0-1-0 — проиграет id, хоть и ниже */
```

### Частые ошибки
- Лечить проблемы через `!important` — потом его придётся перебивать ещё одним `!important`.
- Стилизовать по id и удивляться, почему не перебивается класс.
- Думать, что `background` наследуется. Фон родителя просто «просвечивает», потому что у ребёнка фон прозрачный.

### Мини-задание
Сделай абзац с классом и id и напиши для него четыре противоречащих правила цвета. Сначала угадай победителя, затем проверь в DevTools, какие правила зачёркнуты.

### На пальцах
Единицы измерения — как разные линейки. `px` — сантиметровая линейка: всегда одинаково. `rem` — «столько-то ладоней»: если человек увеличил шрифт в настройках, ладонь стала больше, и все размеры выросли вместе. `%` — доля от родителя. `vw` — доля ширины окна.

### Как это работает
Цвета:

- `#1f4fd8` — шестнадцатеричная запись, самая распространённая.
- `rgb(31 79 216)` и с прозрачностью `rgb(31 79 216 / 50%)`.
- `hsl(225 75% 48%)` — тон, насыщенность, светлота. Удобно делать оттенки одного цвета.
- Названия: `white`, `black`, `transparent`.

Единицы:

| Единица | Относительно чего | Где применять |
|---|---|---|
| `px` | ни от чего | рамки, тени, мелкие детали |
| `rem` | размер шрифта `html` (обычно 16px) | шрифты, отступы |
| `em` | размер шрифта самого элемента | отступы внутри кнопки, зависящие от её текста |
| `%` | размер родителя | ширина колонок |
| `vw` / `vh` | ширина / высота окна | полноэкранные блоки |

Почему шрифты в `rem`: пользователь со слабым зрением ставит в браузере шрифт 20px вместо 16px. Тексты в `rem` вырастут, а в `px` — останутся мелкими.

### Пример
```css
html { font-size: 100%; }      /* обычно 16px */

body {
  font-size: 1rem;             /* 16px */
  color: hsl(210 30% 15%);
}

h1 { font-size: 2.5rem; }      /* 40px */

.container {
  width: 90%;
  max-width: 1200px;
  margin: 0 auto;
}

.hero {
  min-height: 80vh;
  background: rgb(31 79 216 / 10%);
}

.card { border: 1px solid #d3dae1; }
```

### Частые ошибки
- `height: 100vh` на телефоне — из-за адресной строки блок оказывается выше экрана. Используй `100dvh` или `min-height`.
- Все шрифты в `px`.
- `%` у высоты, когда у родителя высота не задана — не сработает.

### Мини-задание
Переведи все размеры шрифтов на своей странице в `rem`. Затем в настройках браузера увеличь шрифт по умолчанию и проверь, что страница масштабируется аккуратно.

### На пальцах
Шрифт — голос сайта. Один и тот же текст звучит солидно, дружелюбно или технично в зависимости от шрифта. Google Fonts — бесплатная библиотека голосов: выбрал, получил ссылку, подключил.

### Как это работает
1. Зайди на fonts.google.com, выбери шрифт с поддержкой кириллицы (фильтр «Language → Cyrillic»). Хорошие варианты: Inter, Manrope, Golos Text, Montserrat, PT Serif.
2. Выбери только нужные начертания, например 400 (обычный) и 700 (жирный). Каждое лишнее начертание — лишние килобайты.
3. Скопируй код `link` в `head` перед своим CSS.
4. В CSS укажи `font-family` с запасными вариантами через запятую.

Основные свойства текста:

| Свойство | Пример | Что делает |
|---|---|---|
| `font-family` | `"Inter", sans-serif` | шрифт и запасные варианты |
| `font-size` | `1.125rem` | размер |
| `font-weight` | `400`, `700` | насыщенность |
| `line-height` | `1.5` | межстрочный интервал, без единиц |
| `letter-spacing` | `0.02em` | расстояние между буквами |
| `text-transform` | `uppercase` | регистр |

`display=swap` в ссылке Google Fonts значит: пока шрифт грузится, показывать текст системным, а не прятать.

### Пример
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="css/style.css">
```

```css
body {
  font-family: "Manrope", system-ui, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}

h1, h2 {
  font-weight: 700;
  line-height: 1.2;
}
```

### Частые ошибки
- Шрифт без кириллицы — русский текст покажется запасным шрифтом, и дизайн «поплывёт».
- Подключить все 9 начертаний ради одного жирного заголовка.
- Три-четыре разных шрифта на странице. Обычно хватает одного, максимум двух: для заголовков и текста.

### Мини-задание
Подбери для своего сайта пару шрифтов: для заголовков и для текста, оба с кириллицей. Подключи по два начертания и настрой `line-height` так, чтобы длинный абзац читался легко.
