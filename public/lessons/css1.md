### Ситуация
У сайта десять страниц, и заказчик просит: «Сделайте синий чуть темнее». Если стили записаны прямо в тегах каждой страницы — тебя ждёт час поиска и замены, и ты точно что-то пропустишь. Если в одном общем файле — меняешь одну строчку, и все десять страниц обновились. Сейчас разберём, как устроить второй вариант.

### На пальцах
HTML — голые стены и мебель, CSS — ремонт: цвет стен, обои, расстановка. Держать стили в отдельном файле — как иметь один дизайн-проект на весь дом: поменял цвет в одном месте — изменились все комнаты.

### Как это работает
Есть три способа подключить стили:

| Способ | Как | Когда |
|---|---|---|
| Внешний файл | `<link rel="stylesheet" href="css/style.css">` в `head` | почти всегда |
| Тег style | `<style> ... </style>` в `head` | быстрые эксперименты |
| Атрибут style | `<p style="color: red">` | почти никогда |

CSS-правило состоит из селектора и блока объявлений:

```css
селектор {
  свойство: значение;
  свойство: значение;
}
```

?: Почему внешний файл лучше, чем `<style>` в каждой странице, если результат на экране одинаковый? || Один файл обслуживает все страницы — правишь в одном месте. Браузер скачивает его один раз и кеширует, поэтому следующие страницы открываются быстрее. И HTML остаётся чистым: в нём только структура.

### Пример
```html
<!-- index.html -->
<head>
  <meta charset="utf-8">
  <title>Студия</title>
  <link rel="stylesheet" href="css/style.css">
</head>
```

```css
/* css/style.css */
body {
  font-family: system-ui, sans-serif;
  color: #1e2a36;
  background: #f6f7f9;
  margin: 0;
}

h1 {
  font-size: 40px;
  color: #1f4fd8
  margin-bottom: 8px;
}
```

?! В правиле для `h1` есть ошибка. Каким получится заголовок: какой цвет, размер и отступ снизу? || Размер 40px применится. А после `#1f4fd8` нет точки с запятой, поэтому браузер прочитает `color: #1f4fd8 margin-bottom: 8px` как одно сломанное значение и выбросит оба объявления. Заголовок будет цвета текста `body`, без отступа 8px.

### Частые ошибки
- **Неверный путь в `href`** — стили просто не применятся. Открой Network: файл с кодом 404 сразу выдаст опечатку.
- **Пропущенная точка с запятой** ломает не одно, а два объявления — текущее и следующее.
- **Стили в атрибутах `style` по всей странице** — их невозможно найти и поддерживать.

### Проверь себя
?? Какие три способа подключить CSS ты знаешь и какой основной? || Внешний файл через `link`, тег `style` в `head` и атрибут `style`. Основной — внешний файл.
?? Из чего состоит CSS-правило? || Из селектора и блока объявлений в фигурных скобках, где каждое объявление — `свойство: значение;`.
?? Объясни своими словами, почему пропущенная `;` может сломать сразу два свойства. || Браузер считает, что объявление продолжается до следующей точки с запятой, склеивает два свойства в одно непонятное значение и отбрасывает его целиком.

### Ситуация
Ты пишешь `a { color: red; }`, чтобы покрасить ссылки в меню, — и вдруг краснеют вообще все ссылки на сайте, включая подвал и текст статей. Нужен способ сказать браузеру точнее: «не всем ссылкам, а только тем, что в меню». Для этого есть селекторы, и их не так много, как кажется.

### На пальцах
Селектор — адресат приказа. «Всем сотрудникам» — селектор по тегу. «Всем из отдела продаж» — по классу. «Ивану Петрову лично» — по id. «Всем, кто сидит в переговорной» — селектор потомка. «Тому, на кого навели указку» — `:hover`.

### Как это работает
| Селектор | Пример | Кого выберет |
|---|---|---|
| тег | `p` | все абзацы |
| класс | `.card` | все элементы с `class="card"` |
| id | `#header` | один элемент с `id="header"` |
| потомок | `.menu a` | все ссылки внутри `.menu` на любой глубине |
| дочерний | `.menu > li` | только прямые дети |
| несколько | `h1, h2` | и те, и другие |
| псевдокласс | `a:hover` | ссылку под курсором |

Другие полезные псевдоклассы: `:focus-visible` (фокус с клавиатуры), `:first-child`, `:last-child`, `:nth-child(2n)` (каждый второй), `:disabled`, `:checked`.

У элемента может быть несколько классов через пробел: `class="btn btn--primary"`.

?: Почему стилизуют в основном через классы, а не через id? || Класс можно повесить на сколько угодно элементов и переиспользовать. А у id слишком большой «вес»: правило по id потом почти невозможно перебить классом, и стили начинают воевать.

### Пример
```css
.card {
  padding: 16px;
  border: 1px solid #d3dae1;
  border-radius: 12px;
}

.card h3 {
  margin-top: 0;
}

.btn:hover {
  background: #1a43b8;
}

.list li:nth-child(odd) {
  background: #f1f4f7;
}
```

?! В списке `.list` шесть пунктов. Какие из них получат серый фон? || Первый, третий и пятый: `odd` — нечётные. Для чётных было бы `even` или `2n`.

### Частые ошибки
- **Забыта точка перед классом:** `card { }` ищет несуществующий тег `<card>`, и ничего не происходит.
- **Точка в HTML:** `class=".card"` — так класс называется «.card» с точкой, и селектор `.card` его не найдёт.
- **Километровые селекторы:** `body main section div ul li a` — хрупко: поменял вёрстку, и стиль отвалился.

### Проверь себя
?? Чем `.menu a` отличается от `.menu > a`? || `.menu a` — все ссылки внутри `.menu` на любой глубине. `.menu > a` — только прямые дети `.menu`.
?? Как выбрать элемент под курсором мыши? || Псевдоклассом `:hover`, например `.btn:hover`.
?? Объясни своими словами, что такое селектор. || Указание, к каким элементам страницы применить правило: по тегу, классу, id, положению или состоянию.

### Ситуация
Ты пишешь `.title { color: blue; }`, сохраняешь — заголовок остаётся красным. Пишешь ещё раз ниже — красный. Добавляешь `!important` — синий, ура! Через неделю на сайте пятнадцать `!important`, и никто не понимает, какое правило главное. Так выглядит война с каскадом. Разберёмся в его правилах, чтобы не воевать, а договариваться.

### На пальцах
Каскад — порядок старшинства приказов. Если начальник отдела сказал «красный», а директор лично тебе — «синий», победит директор (специфичность). Если два одинаково важных приказа противоречат — действует последний (порядок). Наследование — как фамилия: цвет текста передаётся от родителя детям сам.

### Как это работает
Когда к элементу применяются противоречащие правила, браузер решает так:

1. **Важность**: `!important` побеждает всё. Пользоваться почти никогда не нужно.
2. **Специфичность** — «вес» селектора, три числа: сколько id, сколько классов, сколько тегов.
3. **Порядок**: при равном весе побеждает правило, написанное ниже.

| Селектор | Вес |
|---|---|
| `p` | 0-0-1 |
| `.card p` | 0-1-1 |
| `.card .title` | 0-2-0 |
| `#main .title` | 1-1-0 |

Веса сравнивают слева направо: один id тяжелее любого количества классов.

Наследование: свойства текста (`color`, `font-family`, `font-size`, `line-height`) передаются детям. Свойства коробки (`margin`, `padding`, `border`, `background`) — нет. Поэтому шрифт и цвет удобно задать один раз у `body`.

?: Почему `background` не наследуется, хотя фон родителя виден у ребёнка? || У ребёнка фон по умолчанию прозрачный, и сквозь него просто просвечивает фон родителя. Если бы фон наследовался, каждая вложенная картинка-фон повторялась бы во всех детях.

### Пример
```html
<p class="note" id="first">Кто победит?</p>
```

```css
p { color: black; }
.note { color: green; }
#first { color: red; }
.note { color: blue; }
```

?! Какого цвета будет текст? Посчитай веса, прежде чем открывать ответ. || Красного. `#first` весит 1-0-0, и он тяжелее любого класса (0-1-0). Синее правило написано ниже, но порядок решает только при равном весе.

В DevTools → Elements → Styles видно все правила элемента. Проигравшие — перечёркнуты.

### Частые ошибки
- **Лечить всё через `!important`** — потом его придётся перебивать ещё одним `!important`, и так до бесконечности.
- **Стилизовать по id** и удивляться, почему класс не перебивает.
- **Считать, что `background` наследуется.** Он просвечивает, а не наследуется.

### Проверь себя
?? В каком порядке браузер решает конфликт правил? || Сначала важность (`!important`), затем специфичность, затем порядок: при равном весе побеждает правило ниже.
?? Какой вес у селектора `.card .title`? || 0-2-0: ноль id, два класса, ноль тегов.
?? Объясни своими словами, что такое наследование в CSS. || Некоторые свойства, в основном текстовые, автоматически передаются от родителя ко всем вложенным элементам. Поэтому шрифт достаточно задать у `body`.

### Ситуация
Пожилой клиент жалуется: «У вас на сайте мелкий текст». Ты смотришь — нормальный 16px. А у него в браузере стоит увеличенный шрифт, и все сайты вокруг крупные, кроме твоего. Потому что ты задал размеры в пикселях, а пиксель упрямо игнорирует настройки человека. Выбор единицы измерения — это вопрос уважения к пользователю.

### На пальцах
Единицы измерения — разные линейки. `px` — сантиметровая линейка: всегда одинаково. `rem` — «столько-то ладоней»: человек увеличил шрифт в настройках, ладонь стала больше, и все размеры выросли вместе. `%` — доля от родителя. `vw` — доля ширины окна.

### Как это работает
Цвета:

- `#1f4fd8` — шестнадцатеричная запись, самая распространённая.
- `rgb(31 79 216)` и с прозрачностью `rgb(31 79 216 / 50%)`.
- `hsl(225 75% 48%)` — тон, насыщенность, светлота. Удобно делать оттенки одного цвета.
- Названия: `white`, `black`, `transparent`.

Единицы:

| Единица | Относительно чего | Где применять |
|---|---|---|
| `px` | ни от чего | рамки, тени, мелкие детали |
| `rem` | размер шрифта `html` (обычно 16px) | шрифты, отступы |
| `em` | размер шрифта самого элемента | отступы внутри кнопки, зависящие от её текста |
| `%` | размер родителя | ширина колонок |
| `vw` / `vh` | ширина / высота окна | полноэкранные блоки |

?: Почему с `hsl` удобнее делать оттенки, чем с `#hex`? || В `hsl` светлота — отдельное число. Чтобы сделать кнопку темнее при наведении, меняешь только `48%` на `40%`, и тон остаётся тем же. С `#1f4fd8` пришлось бы подбирать новый код вслепую.

### Пример
```css
html { font-size: 100%; }

h1 { font-size: 2.5rem; }

.container {
  width: 90%;
  max-width: 1200px;
  margin: 0 auto;
}

.hero {
  min-height: 80vh;
  background: rgb(31 79 216 / 10%);
}
```

?! Пользователь поставил в браузере шрифт по умолчанию 20px вместо 16px. Какого размера станет `h1`? А ширина `.container` на экране 1000px? || `h1` — 50px (2,5 × 20). Ширина `.container` от шрифта не зависит: 90% от 1000px = 900px.

### Частые ошибки
- **`height: 100vh` на телефоне** — из-за адресной строки блок выше экрана. Используй `100dvh` или `min-height`.
- **Все шрифты в `px`** — текст не реагирует на настройки зрения пользователя.
- **`%` у высоты**, когда у родителя высота не задана, — не сработает: не от чего считать.

### Проверь себя
?? От чего считается `rem`? || От размера шрифта корневого элемента `html`, обычно 16px.
?? Где уместнее `px`, а где `rem`? || `px` — для рамок, теней и мелких деталей. `rem` — для шрифтов и отступов.
?? Объясни своими словами, почему шрифты лучше задавать в `rem`. || Тогда они растут вместе с настройкой шрифта в браузере, и человеку со слабым зрением сайт тоже удобно читать.

### Мини-задание
Переведи все размеры шрифтов на своей странице в `rem`. Затем в настройках браузера увеличь шрифт по умолчанию и проверь, что страница масштабируется аккуратно.

### Ситуация
Ты нашёл красивый шрифт в Google Fonts, подключил — на английском всё великолепно. А русский текст выглядит совсем иначе: другая толщина, другие пропорции, макет «поплыл». У шрифта просто нет кириллицы, и браузер тихо подставил запасной. Выбор шрифта начинается с одного фильтра.

### На пальцах
Шрифт — голос сайта. Один и тот же текст звучит солидно, дружелюбно или технично в зависимости от шрифта. Google Fonts — бесплатная библиотека голосов: выбрал, получил ссылку, подключил.

### Как это работает
1. Зайди на fonts.google.com, выбери шрифт с кириллицей (фильтр «Language → Cyrillic»). Хорошие варианты: Inter, Manrope, Golos Text, Montserrat, PT Serif.
2. Выбери только нужные начертания, например 400 и 700. Каждое лишнее — лишние килобайты.
3. Скопируй код `link` в `head` перед своим CSS.
4. В CSS укажи `font-family` с запасными вариантами через запятую.

| Свойство | Пример | Что делает |
|---|---|---|
| `font-family` | `"Inter", sans-serif` | шрифт и запасные варианты |
| `font-size` | `1.125rem` | размер |
| `font-weight` | `400`, `700` | насыщенность |
| `line-height` | `1.5` | межстрочный интервал, без единиц |
| `letter-spacing` | `0.02em` | расстояние между буквами |
| `text-transform` | `uppercase` | регистр |

?: Зачем в `font-family` писать запасные шрифты через запятую? || Если основной не загрузился — медленный интернет, блокировка, нет нужных символов — браузер возьмёт следующий из списка. Без запасных он подставит шрифт по умолчанию, обычно Times New Roman.

`display=swap` в ссылке Google Fonts значит: пока шрифт грузится, показывать текст системным, а не прятать.

### Пример
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="css/style.css">
```

```css
body {
  font-family: "Manrope", system-ui, sans-serif;
  line-height: 1.6;
}

h1, h2 {
  font-weight: 700;
  line-height: 1.2;
}

h3 { font-weight: 600; }
```

?! Каким получится `h3`, если подключены только начертания 400 и 700? || Браузер подставит ближайшее доступное начертание — скорее всего 700 — или попытается сам «нарисовать» жирность, что выглядит грубо. Нужное начертание надо подключить.

### Частые ошибки
- **Шрифт без кириллицы** — русский текст покажется запасным шрифтом, и дизайн «поплывёт».
- **Все 9 начертаний ради одного жирного заголовка** — лишние сотни килобайт.
- **Три-четыре шрифта на странице.** Обычно хватает одного, максимум двух: для заголовков и текста.

### Проверь себя
?? Какой фильтр обязательно включить в Google Fonts для русского сайта? || «Language → Cyrillic» — поддержку кириллицы.
?? Почему `line-height` пишут без единиц, например `1.5`? || Так интервал считается от размера шрифта каждого элемента и правильно наследуется при разных размерах текста.
?? Объясни своими словами, что делает `display=swap`. || Пока фирменный шрифт загружается, текст показывается системным, а не прячется. Человек может читать сразу.

### Мини-задание
Подбери для своего сайта пару шрифтов: для заголовков и для текста, оба с кириллицей. Подключи по два начертания и настрой `line-height` так, чтобы длинный абзац читался легко. Сравни, как тот же абзац читается с `line-height: 1.2` и `1.6`.
