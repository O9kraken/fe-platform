### На пальцах
Массив — поезд с пронумерованными вагонами. Нумерация начинается с нуля: первый вагон — № 0. `length` — сколько вагонов в составе. `push` — прицепить вагон в конец. `slice` — сфотографировать часть поезда, не отцепляя вагоны.

### Как это работает
- Создание: `const fruits = ["яблоко", "груша", "слива"]`.
- Доступ по индексу: `fruits[0]` — первый элемент, `fruits[fruits.length - 1]` или `fruits.at(-1)` — последний.
- `length` — количество элементов.
- Методы, которые **меняют** массив: `push` (в конец), `pop` (убрать последний), `unshift` (в начало), `shift` (убрать первый), `splice` (вырезать или вставить в середине), `sort`, `reverse`.
- Методы, которые **не меняют** и возвращают новое: `slice(начало, конец)` (конец не включается), `concat`, `map`, `filter`, `[...arr]`.
- Поиск: `includes(x)` — есть ли, `indexOf(x)` — под каким номером (или -1).
- `join(", ")` — склеить в строку, `"a,b".split(",")` — разрезать строку в массив.

### Пример
```js
const tasks = ["вёрстка", "стили", "скрипты"];

console.log(tasks[0]);          // вёрстка
console.log(tasks.at(-1));      // скрипты
console.log(tasks.length);      // 3

tasks.push("деплой");           // ["вёрстка", "стили", "скрипты", "деплой"]
const first2 = tasks.slice(0, 2); // ["вёрстка", "стили"], tasks не изменился

console.log(tasks.includes("стили"));  // true
console.log(tasks.indexOf("тесты"));   // -1 — нет такого
console.log(tasks.join(" → "));        // вёрстка → стили → скрипты → деплой

const tags = "html,css,js".split(",");  // ["html", "css", "js"]
```

### Частые ошибки
- Ждать, что `tasks[3]` при трёх элементах даст ошибку. Он даст `undefined`.
- Путать `slice` (копирует кусок) и `splice` (вырезает из исходного).
- Сохранять результат `push` в переменную: `push` возвращает новую длину, а не массив.

### На пальцах
Объект — анкета с полями: «Имя: Анна», «Город: Москва», «Возраст: 27». Точка — когда название поля знаешь заранее: «покажи графу Город». Квадратные скобки — когда название поля написано на бумажке и может меняться: «покажи графу, которая указана вот здесь».

### Как это работает
- Создание: `const user = { name: "Анна", age: 27 }`. Слева ключ, справа значение.
- Чтение: `user.name` или `user["name"]`.
- Запись: `user.city = "Москва"` — добавит новое поле или изменит существующее.
- Удаление: `delete user.age`.
- Нет такого поля — получишь `undefined`, не ошибку.
- Квадратные скобки нужны, если ключ в переменной (`user[field]`) или в ключе есть пробел и дефис (`obj["full-name"]`).
- Короткая запись: если переменная называется так же, как ключ, — `{ name, age }` вместо `{ name: name, age: age }`.
- Перебор: `Object.keys(obj)`, `Object.values(obj)`, `Object.entries(obj)` (пары ключ-значение).
- Проверка наличия поля: `"city" in user`.

Значением может быть что угодно: массив, другой объект, функция (тогда это метод).

### Пример
```js
const project = {
  title: "Лендинг кофейни",
  budget: 40000,
  tags: ["вёрстка", "SEO"],
  client: { name: "Kofeby", city: "Минск" },
};

console.log(project.title);           // Лендинг кофейни
console.log(project.client.city);     // Минск
console.log(project.tags[1]);         // SEO

const field = "budget";
console.log(project[field]);          // 40000

project.status = "в работе";           // добавили поле
delete project.budget;                // удалили

for (const [key, value] of Object.entries(project)) {
  console.log(key, "→", value);
}

const name = "Анна", city = "Москва";
const user = { name, city };          // { name: "Анна", city: "Москва" }
```

### Частые ошибки
- `user.field` вместо `user[field]`, когда ключ в переменной — ищется поле с именем «field».
- Обращение к полю у `undefined`: `project.manager.name` при отсутствии `manager` — ошибка. Используй `project.manager?.name`.
- Копировать объект присваиванием: `const copy = user` — это та же коробка. Копия: `{ ...user }`.

### На пальцах
Методы массивов — конвейер на фабрике. `map` — станок, который каждую деталь превращает во что-то другое. `filter` — контролёр, который пропускает только годные. `find` — ищет первую подходящую деталь. `some` — проверка «есть хоть одна бракованная?». `reduce` — упаковщик, собирающий всё в одну коробку. `sort` — расставить по порядку.

### Как это работает
Все методы принимают функцию, которая вызывается для каждого элемента.

| Метод | Возвращает | Пример |
|---|---|---|
| `map(fn)` | новый массив той же длины | цены → цены со скидкой |
| `filter(fn)` | новый массив тех, где fn вернула true | только активные |
| `find(fn)` | первый подходящий элемент или undefined | пользователь с id 5 |
| `some(fn)` | true, если хоть один подходит | есть ли просроченные |
| `every(fn)` | true, если подходят все | все ли оплачены |
| `reduce(fn, start)` | одно значение | сумма, объект-группировка |
| `sort(fn)` | тот же массив, отсортированный | по цене |

`reduce((acc, item) => ..., начальное)` — `acc` («аккумулятор») — то, что накопили к текущему шагу. Функция возвращает новое значение аккумулятора.

`sort` по умолчанию сравнивает как строки, поэтому числа сортируют так: `sort((a, b) => a - b)` (по возрастанию). Он меняет исходный массив — сначала скопируй.

Методы можно соединять в цепочку: `filter` → `map` → `reduce`.

### Пример
```js
const orders = [
  { id: 1, client: "Анна", sum: 1500, paid: true },
  { id: 2, client: "Борис", sum: 3200, paid: false },
  { id: 3, client: "Вика", sum: 800, paid: true },
];

const sums = orders.map(o => o.sum);                    // [1500, 3200, 800]
const paid = orders.filter(o => o.paid);                // Анна и Вика
const boris = orders.find(o => o.client === "Борис");   // объект Бориса
const hasDebt = orders.some(o => !o.paid);              // true
const revenue = orders
  .filter(o => o.paid)
  .reduce((acc, o) => acc + o.sum, 0);                  // 2300
const bySum = [...orders].sort((a, b) => b.sum - a.sum); // от большего к меньшему

console.log(sums, paid.length, boris.id, hasDebt, revenue, bySum[0].client);
```

### Частые ошибки
- Забыть `return` в функции с фигурными скобками: `map(o => { o.sum })` даст массив `undefined`.
- `reduce` без начального значения на пустом массиве — ошибка.
- `sort()` для чисел без функции: `[10, 9, 1].sort()` → `[1, 10, 9]`.

### Мини-задание
Возьми массив товаров с названием, ценой и наличием. Получи: список названий, только товары в наличии, самый дорогой товар, общую стоимость товаров в наличии. Используй цепочку методов. Посмотри схему «map, filter, reduce — конвейер» в этом уроке.

### На пальцах
Деструктуризация — распаковка посылки: вместо «открой коробку, достань чашку, достань блюдце» ты одной фразой говоришь «чашку сюда, блюдце туда». Spread `...` — высыпать содержимое одной коробки в другую: удобно, чтобы сделать копию или объединить две коробки.

### Как это работает
Деструктуризация объекта — по именам полей:

```js
const { name, city = "Не указан", contacts: { email } } = user;
```

Можно задать значение по умолчанию и переименовать: `const { name: userName } = user`.

Деструктуризация массива — по позиции:

```js
const [first, second, ...rest] = list;
```

Spread `...` раскладывает:

- `[...arr, 4]` — копия массива с новым элементом;
- `{ ...obj, city: "Казань" }` — копия объекта с изменённым полем (поле справа перезапишет);
- `Math.max(...nums)` — передать элементы массива как отдельные аргументы.

Деструктуризация в параметрах функции — очень частый приём, особенно в React: `function Card({ title, price }) { ... }`.

Spread делает поверхностную копию: вложенные объекты остаются общими.

### Пример
```js
const user = { name: "Анна", age: 27, contacts: { email: "a@mail.ru" } };

const { name, age } = user;
const { contacts: { email } } = user;
console.log(name, age, email);

const [winner, runnerUp, ...others] = ["Анна", "Борис", "Вика", "Глеб"];
console.log(winner, others);        // Анна ["Вика", "Глеб"]

const updated = { ...user, age: 28 };          // копия с новым возрастом
const list = [1, 2, 3];
const longer = [...list, 4];                   // [1, 2, 3, 4]
console.log(Math.max(...list));                // 3

function card({ title, price = 0 }) {
  return `${title}: ${price} ₽`;
}
console.log(card({ title: "Лендинг", price: 30000 }));

let a = 1, b = 2;
[a, b] = [b, a];                                // обмен значениями
```

### Частые ошибки
- Деструктурировать `undefined`: `const { name } = undefined` — ошибка. Дай значение по умолчанию: `= {}`.
- Думать, что spread копирует глубоко: `copy.contacts.email = "..."` изменит и исходный объект.
- Порядок в spread объектов: `{ age: 28, ...user }` — возраст перезапишется старым.

### Мини-задание
Из объекта заказа `{ id, client: { name, phone }, items: [...] }` одной строкой достань имя клиента и первый товар. Сделай копию заказа с новым статусом через spread, не меняя исходный.

### На пальцах
Почти всё, что ты видишь на сайтах, — список одинаковых карточек: товары, посты, задачи, сообщения, отзывы. А за каждым таким списком в коде стоит одно и то же — массив объектов. Научился с ним работать — понимаешь 80% фронтенда.

### Как это работает
С сервера данные почти всегда приходят как массив объектов в формате JSON:

```js
[
  { "id": 1, "title": "Кроссовки", "price": 5990, "category": "обувь" },
  { "id": 2, "title": "Куртка",    "price": 8990, "category": "одежда" }
]
```

Типичные операции, которые ты будешь делать всю карьеру:

| Задача | Метод |
|---|---|
| Показать список | `map` → HTML или компоненты |
| Поиск и фильтр | `filter` |
| Найти по id | `find` |
| Сортировка | `[...arr].sort(...)` |
| Итоги, суммы | `reduce` |
| Добавить | `[...arr, newItem]` |
| Изменить один | `arr.map(x => x.id === id ? { ...x, done: true } : x)` |
| Удалить | `arr.filter(x => x.id !== id)` |

У каждого объекта должен быть уникальный `id` — по нему находят, меняют и удаляют элементы.

### Пример
```js
let todos = [
  { id: 1, text: "Сверстать шапку", done: true },
  { id: 2, text: "Подключить шрифты", done: false },
  { id: 3, text: "Задеплоить", done: false },
];

// добавить
todos = [...todos, { id: 4, text: "Написать README", done: false }];
// отметить выполненной
todos = todos.map(t => t.id === 2 ? { ...t, done: true } : t);
// удалить
todos = todos.filter(t => t.id !== 3);
// показать
const html = todos
  .map(t => `<li class="${t.done ? "done" : ""}">${t.text}</li>`)
  .join("");
console.log(html);
console.log(`Осталось: ${todos.filter(t => !t.done).length}`);
```

### Частые ошибки
- Искать и удалять по индексу вместо `id` — после сортировки или фильтра индексы меняются.
- Менять объект прямо в массиве (`todos[1].done = true`) там, где нужна неизменяемость (React).
- Вставлять в HTML пользовательский текст через шаблонную строку без экранирования — так появляется XSS. Позже научимся делать это безопасно.
