### На пальцах
HTML-документ похож на человека: `html` — всё тело целиком, `head` — голова, где мысли и паспортные данные (их не видно снаружи), `body` — всё, что видно окружающим. `<!doctype html>` — табличка на входе: «здесь современный HTML, читай по новым правилам».

### Как это работает
Минимальный правильный документ:

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Анна — начинающий разработчик</title>
</head>
<body>
  <h1>Привет, я Анна</h1>
  <p>Учусь делать сайты.</p>
</body>
</html>
```

Разбор по строкам:

- `<!doctype html>` — без него браузер включает «режим совместимости» со старыми сайтами и может по-другому считать размеры.
- `<html lang="ru">` — корень документа и язык страницы. Язык нужен скринридерам (правильное произношение) и переводчикам.
- `<meta charset="utf-8">` — кодировка. Без неё русский текст может превратиться в «кракозябры».
- `<meta name="viewport" ...>` — чтобы на телефоне страница не показывалась уменьшенной копией компьютерной версии.
- `<title>` — текст на вкладке браузера и заголовок в результатах поиска.
- `<body>` — всё видимое содержимое.

В VS Code весь этот скелет вставляется одной командой: набери `!` в пустом `.html` файле и нажми Tab.

### Частые ошибки
- Писать текст и теги вне `body` — браузер «простит», но это ошибка разметки.
- Забыть `charset` — и получить вопросики вместо букв.
- Оставить `lang="en"` из шаблона на русской странице.

### Мини-задание
Создай `about.html` со всем скелетом руками, без `!` + Tab. Укажи `lang="ru"`, осмысленный `title`, заголовок и абзац. Открой и проверь, что текст на вкладке совпадает с `title`.

### На пальцах
Заголовки — оглавление книги: h1 — название книги, h2 — главы, h3 — разделы внутри глав. Абзац — обычный блок текста. Ссылка — дверь на другую страницу. Картинка — фотография, вклеенная в текст, с подписью для тех, кто её не видит.

### Как это работает
- `h1`–`h6` — заголовки шести уровней. На странице один `h1`, дальше иерархия без прыжков: после `h2` идёт `h3`, а не `h5`.
- `p` — абзац. Браузер сам добавит отступы сверху и снизу.
- `a` — ссылка. Адрес в атрибуте `href`. Для внешних сайтов можно добавить `target="_blank"` — откроется в новой вкладке.
- `img` — картинка. Одиночный тег без закрывающей пары. Обязательные атрибуты: `src` (откуда взять) и `alt` (что изображено).

Размер заголовка выбирают по смыслу, а не по виду. Нужен мелкий, но главный заголовок — ставь `h1` и уменьши его в CSS.

### Пример
```html
<h1>Рецепты бабушки</h1>

<h2>Выпечка</h2>
<p>Здесь собраны рецепты, которые получаются с первого раза.</p>

<h3>Сырники</h3>
<p>Понадобится творог, яйцо и немного муки.</p>
<img src="img/syrniki.jpg" alt="Пять румяных сырников на белой тарелке">

<p>Больше рецептов — на <a href="https://eda.ru" target="_blank">eda.ru</a>.</p>
<p><a href="contacts.html">Написать мне</a></p>
```

### Частые ошибки
- Несколько `h1` на странице или заголовки, выбранные «по размеру шрифта».
- Писать текст без `p`, разделяя строки через `<br>`. `br` — для переноса внутри адреса или стихотворения, не для абзацев.
- Ссылка с текстом «здесь» или «тут». Текст ссылки должен говорить, куда она ведёт: «Скачать прайс-лист».

### Мини-задание
Свёрстай страницу «Мои любимые фильмы»: `h1`, по `h2` на каждый фильм, абзац с описанием, постер с осмысленным `alt` и ссылку на страницу фильма на «Кинопоиске».

### На пальцах
`ul` — список покупок: порядок не важен, перед каждым пунктом точка. `ol` — инструкция по сборке шкафа: порядок важен, пункты пронумерованы. `li` — один пункт любого списка.

### Как это работает
- `ul` (unordered list) — маркированный список.
- `ol` (ordered list) — нумерованный.
- Внутри `ul` и `ol` могут лежать только `li`. Текст, абзацы и другие теги кладутся внутрь `li`.
- Списки можно вкладывать: внутри `li` — ещё один `ul`.
- У `ol` есть полезные атрибуты: `start="5"` начинает с пятёрки, `reversed` считает в обратную сторону.

Меню сайта — тоже список ссылок, поэтому его верстают через `ul` внутри `nav`. Скринридер скажет «список из 5 элементов», и человек сразу понимает масштаб.

### Пример
```html
<h2>Что купить</h2>
<ul>
  <li>Молоко</li>
  <li>Творог
    <ul>
      <li>для сырников — 500 г</li>
      <li>к завтраку — 200 г</li>
    </ul>
  </li>
  <li>Яйца</li>
</ul>

<h2>Как приготовить</h2>
<ol>
  <li>Смешай творог, яйцо и муку.</li>
  <li>Сформируй шарики и обваляй в муке.</li>
  <li>Жарь по 3 минуты с каждой стороны.</li>
</ol>
```

### Частые ошибки
- Класть текст прямо в `ul` без `li`.
- Ставить нумерацию руками: `<li>1. Смешай...</li>` при `ol` — получится «1. 1. Смешай».
- Делать список из абзацев с дефисами в начале вместо настоящего `ul`.

### Мини-задание
Добавь на страницу рецепта список ингредиентов и пронумерованные шаги. Сделай вложенный список для одного ингредиента с вариантами.

### На пальцах
Тег — это предмет, а атрибут — его характеристика на бирке. Предмет «картинка», бирки: «откуда взять — photo.jpg», «что изображено — кот на подоконнике». Без бирок предмет есть, но непонятно, что с ним делать.

### Как это работает
Атрибуты пишутся в открывающем теге: `имя="значение"`.

| Атрибут | У какого тега | Зачем |
|---|---|---|
| `href` | `a`, `link` | куда ведёт ссылка, какой файл подключить |
| `src` | `img`, `script` | откуда загрузить картинку или скрипт |
| `alt` | `img` | текстовое описание картинки |
| `lang` | `html` и любой | язык содержимого |

Про `alt` подробнее. Его читают скринридеры незрячим людям, показывают вместо картинки, если она не загрузилась, и учитывают поисковики. Пиши, что на картинке и зачем она: «Схема проезда от метро до офиса». Для чисто декоративной картинки ставь пустой `alt=""` — тогда скринридер её пропустит.

`lang` у отдельного элемента нужен, когда внутри русской страницы есть фраза на другом языке: `<p lang="en">Hello, world!</p>`.

Значения пишут в двойных кавычках. Есть и атрибуты без значения: `<input required>`.

### Пример
```html
<html lang="ru">
...
<a href="https://github.com/anna">Мой GitHub</a>
<a href="mailto:anna@example.com">Написать на почту</a>
<a href="tel:+79991234567">Позвонить</a>

<img src="img/team.jpg" alt="Команда студии на фоне офиса, пять человек">
<img src="img/wave.svg" alt="">

<blockquote lang="en">Stay hungry, stay foolish.</blockquote>
```

### Частые ошибки
- `alt="картинка"` или `alt="IMG_2034"` — ничего не сообщает.
- Забыть кавычки или поставить разные: `href='page.html"`.
- Опечатка в имени атрибута (`scr` вместо `src`) — браузер молча проигнорирует.

### Мини-задание
Добавь на страницу три ссылки: на внешний сайт, на почту через `mailto:` и на телефон через `tel:`. Добавь две картинки: содержательную с хорошим `alt` и декоративную с пустым.

### На пальцах
Теги вкладываются как матрёшки: каждую нужно закрыть внутри той, в которой открыл. Нельзя закрыть большую матрёшку, пока внутри открыта маленькая. Отступы — как отступы в оглавлении: сразу видно, что во что вложено.

### Как это работает
- Тег, открытый внутри другого, закрывается раньше внешнего: `<p><strong>важно</strong></p>`.
- Неправильно: `<p><strong>важно</p></strong>` — теги «перекрещиваются».
- Вложенные элементы называют детьми, внешний — родителем. Эти слова понадобятся в CSS и JavaScript.
- Каждый уровень вложенности сдвигается на 2 пробела. Prettier в VS Code сделает это сам при сохранении.

Есть одиночные теги без закрывающей пары: `img`, `br`, `hr`, `input`, `meta`, `link`.

Есть и правила, что во что можно класть. Например, в `p` нельзя класть блочные элементы — `div`, `ul`, другой `p`. Браузер молча «починит» разметку, и результат окажется не таким, как ты думал.

### Пример
```html
<article>
  <h2>Как я выучил Git</h2>
  <p>
    Сначала было <em>страшно</em>, но три команды
    <code>add</code>, <code>commit</code>, <code>push</code> решают почти всё.
  </p>
  <ul>
    <li><a href="https://git-scm.com/book/ru/v2">Книга Pro Git</a></li>
    <li><a href="https://learngitbranching.js.org">Тренажёр веток</a></li>
  </ul>
</article>
```

### Частые ошибки
- Перекрещённые теги.
- Список внутри абзаца: `<p>Текст <ul>...</ul></p>` — браузер разорвёт абзац.
- Всё в одну строку или без отступов — через неделю ты сам не поймёшь, где что закрывается.

### Мини-задание
Открой свою страницу, удали все отступы и включи форматирование Prettier (Shift + Alt + F). Затем нарочно перекрести два тега, открой в браузере DevTools → Elements и посмотри, как браузер «исправил» разметку.
