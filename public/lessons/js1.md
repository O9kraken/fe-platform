### На пальцах
HTML — актёры на сцене, JavaScript — режиссёр, который говорит им, что делать. Если режиссёр придёт раньше актёров и начнёт командовать пустой сцене — ничего не выйдет. `defer` говорит режиссёру: «Приходи, когда все актёры уже на местах».

### Как это работает
Браузер читает HTML сверху вниз. Встретив `<script src="app.js">` без атрибутов, он останавливается, скачивает и выполняет скрипт и только потом читает дальше. Если скрипт в `head` ищет кнопку, её ещё нет — получаешь `null` и ошибку.

Варианты подключения:

| Как | Что происходит |
|---|---|
| `<script src="app.js">` в `head` | блокирует страницу, элементов ещё нет |
| `<script src="app.js">` перед `</body>` | работает, но скачивание начинается поздно |
| `<script src="app.js" defer>` в `head` | скачивается параллельно, выполняется после разбора всего HTML — лучший вариант |
| `<script type="module" src="app.js">` | ведёт себя как defer и разрешает `import` |

Порядок нескольких `defer`-скриптов сохраняется: сначала первый, потом второй.

### Пример
```html
<head>
  <meta charset="utf-8">
  <title>Счётчик</title>
  <script src="js/app.js" defer></script>
</head>
<body>
  <button id="btn">Нажми меня</button>
</body>
```

```js
// js/app.js — кнопка уже существует, потому что defer
const btn = document.querySelector("#btn");
btn.addEventListener("click", () => alert("Работает!"));
```

### Частые ошибки
- Скрипт в `head` без `defer` и ошибка «Cannot read properties of null».
- Неверный путь к файлу: в Network будет 404, а в Console — тишина.
- Писать весь код внутри `<script>` в HTML. Для учебных примеров можно, для проекта — отдельный файл.

### Мини-задание
Подключи `app.js` в `head` без `defer` и попробуй найти кнопку — посмотри на ошибку в консоли. Затем добавь `defer` и убедись, что всё заработало.

### На пальцах
Консоль — блокнот, в который программа пишет заметки, и окошко, через которое ты можешь задавать ей вопросы. `console.log` — «запиши вот это, я потом посмотрю». Это главный инструмент новичка: не гадай, что лежит в переменной, — выведи её.

### Как это работает
- Открыть: F12 → вкладка Console.
- `console.log(x)` — вывести значение. Можно несколько через запятую: `console.log("сумма:", sum)`.
- `console.warn` — жёлтое предупреждение, `console.error` — красная ошибка.
- `console.table(массив)` — вывести массив объектов таблицей.
- В консоли можно писать код прямо сейчас: посчитать `2 + 2`, найти элемент, вызвать функцию.
- Красная строка ошибки содержит текст и ссылку на файл и строку — кликни, и DevTools покажет место.

Совет: подписывай выводы. `console.log(user)` в пяти местах — и непонятно, какой вывод откуда. `console.log("после фильтра:", user)` — понятно.

### Пример
```js
const name = "Анна";
const age = 27;
console.log("Имя:", name, "возраст:", age);

const users = [
  { name: "Анна", city: "Москва" },
  { name: "Борис", city: "Казань" },
];
console.table(users);

console.warn("Это предупреждение");
console.error("А это ошибка");
```

### Частые ошибки
- Не открывать консоль, когда «ничего не происходит». Там почти всегда есть ответ.
- Оставлять десятки `console.log` в готовом проекте.
- Читать только первое слово ошибки. Читай целиком: «Cannot read properties of undefined (reading 'name')» точно говорит, что `undefined` — то, у чего ты берёшь `name`.

### На пальцах
Переменная — коробка с подписью, в которую кладут значение. `let` — коробка, содержимое которой можно заменить. `const` — коробка, заклеенная скотчем: что положил, то и лежит. `var` — старая коробка из прошлого века, у неё дырявое дно и странные правила, ею больше не пользуются.

### Как это работает
- `const` — для значений, которые не будешь переназначать. Используй по умолчанию.
- `let` — когда значение будет меняться: счётчик, текущий шаг, результат ввода.
- `var` — устаревший способ. У него нет блочной области видимости (переменная «вытекает» из `if` и циклов) и есть «всплытие» — его можно использовать до объявления и получить `undefined` вместо ошибки.

Важный нюанс про `const`: нельзя переназначить саму переменную, но можно менять содержимое объекта или массива внутри.

Имена: латиница, понятно по смыслу, в стиле camelCase: `userName`, `totalPrice`, `isOpen`. Регистр важен: `name` и `Name` — разные переменные.

### Пример
```js
const city = "Москва";
// city = "Казань";        // Ошибка: Assignment to constant variable

let count = 0;
count = count + 1;          // можно
count++;                    // тоже можно, теперь 2

const cart = ["хлеб"];
cart.push("молоко");        // можно: меняем содержимое, а не саму переменную
// cart = [];               // нельзя

if (true) {
  var a = 1;
  let b = 2;
}
console.log(a);             // 1 — var вытек из блока
// console.log(b);          // Ошибка: b is not defined — так и должно быть
```

### Частые ошибки
- Всё через `let` «на всякий случай». Начинай с `const`, меняй на `let`, когда реально нужно.
- Объявлять одну переменную дважды: `let x = 1; let x = 2;` — ошибка.
- Имена `a`, `data2`, `temp` — через день непонятно, что внутри.

### На пальцах
Типы данных — разные виды вещей в коробках: строка — записка с текстом, число — гирька с весом, логическое значение — выключатель «вкл/выкл». `null` — коробка, в которую специально положили табличку «пусто». `undefined` — коробка, в которую ещё ничего не клали.

### Как это работает
| Тип | Пример | Что это |
|---|---|---|
| string | `"Привет"`, `'a'`, `` `шаблон` `` | текст |
| number | `42`, `3.14`, `-7` | число, целое и дробное — один тип |
| boolean | `true`, `false` | да или нет |
| null | `null` | «значения нет» — поставили намеренно |
| undefined | `undefined` | «значение не задано» — так получилось само |

Кроме них есть объекты и массивы — составные типы, о них позже.

Узнать тип: `typeof x`. Особенности:

- `typeof null` возвращает `"object"` — историческая ошибка языка.
- `0.1 + 0.2` даёт `0.30000000000000004` — так устроены дробные числа в компьютере. Для денег считай в копейках.
- `"5" * 2` даёт `10`, а `"5" + 2` — `"52"`: плюс со строкой склеивает.
- `Number("42")` превращает строку в число, `String(42)` — число в строку. `Number("abc")` даёт `NaN` — «не число».

### Пример
```js
const name = "Анна";       // string
const age = 27;            // number
const isStudent = true;    // boolean
let job = null;            // работы пока нет — сказали явно
let phone;                 // undefined — ещё не задали

console.log(typeof name, typeof age, typeof isStudent); // string number boolean
console.log(typeof phone);                              // undefined

const input = "15";                // всё из полей ввода приходит строкой
console.log(input + 5);            // "155"
console.log(Number(input) + 5);    // 20
```

### Частые ошибки
- Складывать значения из полей формы и получать `"155"` вместо `20`.
- Сравнивать с `NaN`: `x === NaN` всегда `false`. Используй `Number.isNaN(x)`.
- Путать `null` и `undefined` и удивляться, что «пусто» бывает двух видов.

### На пальцах
Операторы — кнопки калькулятора: плюс, минус, сравнить. Шаблонная строка — бланк с пропусками: «Уважаемый ___, ваш заказ № ___ готов». Ты не склеиваешь кусочки клеем, а просто подставляешь значения в пропуски.

### Как это работает
Арифметика: `+ - * /`, `%` (остаток от деления), `**` (степень). Остаток полезен: `n % 2 === 0` — число чётное.

Сокращения: `x += 5` (то же, что `x = x + 5`), `x++` (увеличить на 1).

Сравнение: `> < >= <=`, `===` (строго равно), `!==` (строго не равно). Результат — `true` или `false`.

Шаблонные строки пишутся в обратных кавычках `` ` `` (клавиша Ё в английской раскладке). Внутри `${выражение}` подставляет значение — переменную, вычисление, вызов функции. Можно переносить строки.

### Пример
```js
const price = 1500;
const qty = 3;
const total = price * qty;               // 4500
const discount = total >= 4000 ? 10 : 0; // 10

// Склейка плюсами — громоздко:
const msg1 = "Итого: " + total + " ₽, скидка " + discount + "%";

// Шаблонная строка — читается как обычный текст:
const msg2 = `Итого: ${total} ₽, скидка ${discount}%`;
const msg3 = `К оплате: ${total - total * discount / 100} ₽`;

console.log(msg2);   // Итого: 4500 ₽, скидка 10%
console.log(msg3);   // К оплате: 4050 ₽

console.log(17 % 5); // 2
console.log(2 ** 8); // 256
```

### Частые ошибки
- Обычные кавычки вместо обратных: `"Итого: ${total}"` выведет текст буквально, с долларом.
- `=` вместо `===` в сравнении: `if (x = 5)` присваивает, а не сравнивает.
- Деление на ноль даёт `Infinity`, а не ошибку — проверяй делитель.
