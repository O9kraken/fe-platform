### На пальцах
Представь коробку для посылки. Ты заказал коробку шириной 30 см. По старым правилам CSS «30 см» — это только место для вещей, а поролон внутри и стенки добавляются сверху, и коробка выходит 36 см и не влезает в полку. `box-sizing: border-box` говорит: «30 см — это вместе со стенками и поролоном». Так считать гораздо проще.

### Как это работает
Каждый элемент — коробка из четырёх слоёв: содержимое → `padding` (внутренний отступ) → `border` (рамка) → `margin` (внешний отступ).

| box-sizing | Что значит width: 300px | Итоговая ширина при padding 20px и border 1px |
|---|---|---|
| `content-box` (по умолчанию) | ширина только содержимого | 300 + 40 + 2 = 342px |
| `border-box` | ширина вместе с padding и border | 300px |

С `content-box` две колонки по `width: 50%` с отступами не встанут рядом — каждая окажется шире половины. С `border-box` встанут.

Поэтому почти любой проект начинается со строчки, которая включает `border-box` для всех элементов.

### Пример
```css
*,
*::before,
*::after {
  box-sizing: border-box;
}

.col {
  width: 50%;
  padding: 20px;
  border: 1px solid #ccc;
  float: left;   /* только ради демонстрации: две колонки встанут рядом */
}
```

Проверь в DevTools → Elements → вкладка Computed: там нарисована схема коробки с цифрами каждого слоя.

### Частые ошибки
- Забыть сброс и долго искать, откуда лишние пиксели.
- Писать `box-sizing` только для пары элементов — правило нужно всем.
- Путать `padding` и `margin`: фон закрашивает padding, но не margin.

### Мини-задание
Сделай две колонки `width: 50%` с `padding: 20px` и рамкой. Без `border-box` они встанут друг под другом — добавь сброс и посмотри, как они встали рядом. Сверь цифры в схеме Computed.

### На пальцах
`padding` — поролон внутри коробки, `margin` — расстояние между коробками на складе. `width` — ширина коробки, `max-width` — правило склада: «шире 1200 мм не бывает». На маленькой полке коробка сожмётся, на большой — не раздуется до бесконечности.

### Как это работает
- `padding` — отступ внутри элемента, между содержимым и рамкой. Закрашивается фоном.
- `margin` — снаружи, отталкивает соседей. Прозрачный.
- Сокращённая запись по часовой стрелке от верха: `margin: 10px 20px 30px 40px` (верх, право, низ, лево). Два значения: `16px 24px` — вертикаль и горизонталь.
- `margin: 0 auto` у блока с заданной шириной центрирует его по горизонтали.
- `width` — фиксированная ширина. На телефоне жёсткие 1200px вызовут горизонтальную прокрутку.
- `max-width` — «не шире, чем». Элемент сжимается на маленьких экранах.

Особенность: вертикальные margin соседних блоков схлопываются. Если у одного `margin-bottom: 20px`, а у следующего `margin-top: 30px`, расстояние будет 30px, а не 50px. Во flex и grid этого не происходит — там используют `gap`.

### Пример
```css
.container {
  max-width: 1200px;
  margin: 0 auto;        /* по центру */
  padding: 0 16px;       /* чтобы текст не прилипал к краям на телефоне */
}

.card {
  padding: 24px;
  margin-bottom: 16px;
  background: white;
}

.btn {
  padding: 12px 24px;    /* сверху-снизу 12, по бокам 24 */
}
```

### Частые ошибки
- `width: 1200px` вместо `max-width` — горизонтальный скролл на телефоне.
- Делать отступ кнопки через `margin`, когда нужна большая область нажатия. Нажимается padding, а не margin.
- Искать «лишний» отступ, не зная про схлопывание margin.

### Мини-задание
Сделай `.container` с `max-width: 960px` по центру и внутри три карточки с внутренними отступами. Сожми окно до ширины телефона и убедись, что горизонтальной прокрутки нет.

### На пальцах
Блочный элемент — абзац в тетради: занимает всю строку, следующий начинается с новой строки. Строчный — слово в тексте: стоит в строке рядом с другими словами. Строчно-блочный — наклейка в тексте: стоит в строке, но у неё есть свои размеры.

### Как это работает
| display | Как ведёт себя | Ширина и высота | Примеры по умолчанию |
|---|---|---|---|
| `block` | с новой строки, на всю ширину | работают | `div`, `p`, `h1`, `ul`, `section` |
| `inline` | в строку с текстом | не работают, вертикальные margin тоже | `span`, `a`, `strong`, `em` |
| `inline-block` | в строку, но как коробка | работают | `button`, `img` (почти) |
| `none` | элемента нет вовсе | — | — |

Ещё два значения — `flex` и `grid` — превращают элемент в контейнер раскладки. Их разберём отдельно.

Частая ситуация: ссылке-кнопке задали `padding` и `width`, а она «не слушается». Это потому что `a` — inline. Сделай её `inline-block` или `block`.

`display: none` убирает элемент полностью — его не видно и он не занимает место. `visibility: hidden` прячет, но место остаётся.

### Пример
```css
.nav a {
  display: inline-block;
  padding: 10px 16px;
}

.badge {
  display: inline-block;
  padding: 2px 8px;
  border-radius: 99px;
  background: #ffe36b;
}

.mobile-only { display: none; }
```

```html
<p>Статус заказа: <span class="badge">в пути</span></p>
```

### Частые ошибки
- Задавать `width` и `height` строчному элементу и не понимать, почему не работает.
- Лишний отступ под картинкой: `img` ведёт себя как строчный и оставляет место под «хвостик» букв. Лечится `display: block`.
- Прятать текст для скринридера через `display: none` — тогда скринридер его тоже не прочитает.

### Мини-задание

### На пальцах
Flexbox — полка с книгами. Ты решаешь, как стоят книги: в ряд или стопкой (`direction`), прижаты влево, по центру или разнесены по краям (`justify-content`), выровнены по верху или по низу (`align-items`), с каким промежутком (`gap`), и переходят ли на следующую полку, если не влезли (`wrap`).

### Как это работает
`display: flex` вешается на родителя, и его прямые дети выстраиваются по правилам:

| Свойство | Значения | Что делает |
|---|---|---|
| `flex-direction` | `row`, `column` | главная ось: в строку или в столбец |
| `justify-content` | `flex-start`, `center`, `space-between`, `space-around` | раскладка по главной оси |
| `align-items` | `stretch`, `center`, `flex-start`, `flex-end` | выравнивание по поперечной оси |
| `gap` | `16px` | расстояние между элементами |
| `flex-wrap` | `wrap` | переносить на новую строку, если не влезли |

У детей:

- `flex: 1` — «займи всё свободное место». Если у трёх детей `flex: 1`, они поделят ширину поровну.
- `flex-shrink: 0` — «не сжимайся» (полезно для иконок и аватарок).

Важно: при `flex-direction: column` оси меняются местами — `justify-content` работает по вертикали, `align-items` — по горизонтали.

### Пример
```css
/* Шапка: логотип слева, меню справа */
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 24px;
}

/* Карточки, переносятся на новую строку */
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
.cards .card { flex: 1 1 260px; }   /* растягиваться, но не уже 260px */

/* Идеальный центр */
.center {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
```

### Частые ошибки
- Вешать `display: flex` на сами элементы, а не на их родителя.
- Делать отступы между элементами через `margin` у каждого вместо `gap`.
- Путать оси после `flex-direction: column`.

### На пальцах
По умолчанию элементы стоят в очереди один за другим. `relative` — элемент остаётся в очереди, но становится «точкой отсчёта» для вложенных. `absolute` — элемент выходит из очереди и приклеивается к точке отсчёта по координатам, как магнит на холодильнике. `sticky` — элемент едет со страницей, а дойдя до края экрана, прилипает, как шапка таблицы в Excel.

### Как это работает
| position | В потоке? | Относительно чего top/left | Пример |
|---|---|---|---|
| `static` | да | не работают | по умолчанию |
| `relative` | да | своего обычного места | родитель для absolute |
| `absolute` | нет | ближайшего предка с position не static | значок «−20%» на углу карточки |
| `fixed` | нет | окна браузера | кнопка чата в углу |
| `sticky` | да, пока не прилип | края прокручиваемой области | шапка, оглавление |

Правило пары: родителю — `position: relative`, ребёнку — `position: absolute` и координаты. Без relative у родителя ребёнок «улетит» и привяжется к странице.

`z-index` решает, кто кого перекрывает. Работает только у позиционированных элементов.

`sticky` не сработает, если у родителя `overflow: hidden`, и ему обязательно нужна координата, например `top: 0`.

### Пример
```css
.card {
  position: relative;
}

.card .sale {
  position: absolute;
  top: 12px;
  right: 12px;
  background: #c92a2a;
  color: white;
  padding: 4px 8px;
  border-radius: 6px;
}

.header {
  position: sticky;
  top: 0;
  z-index: 10;
  background: white;
}
```

```html
<article class="card">
  <span class="sale">−20%</span>
  <h3>Кроссовки</h3>
</article>
```

### Частые ошибки
- Делать раскладку всей страницы через `absolute` — всё разъедется на другом размере экрана. Для раскладки есть flex и grid.
- Забыть `position: relative` у родителя.
- `z-index: 9999` повсюду вместо понимания, кто кого должен перекрывать.
