### На пальцах
CSS-переменная — банка краски с этикеткой «фирменный синий». Везде, где нужен этот цвет, ты не смешиваешь краску заново, а берёшь из банки. Решили сменить фирменный цвет — перекрасил одну банку, и обновились все стены.

### Как это работает
- Объявление: имя начинается с двух дефисов, обычно в `:root` (это `html`), чтобы переменная была видна везде: `--accent: #1f4fd8;`
- Использование: `color: var(--accent);`
- Запасное значение: `var(--accent, blue)` — если переменная не задана.
- Переменные наследуются и переопределяются: внутри `.dark` можно задать `--bg` иначе, и все вложенные элементы возьмут новое значение.
- Переменные меняются из JavaScript: `document.documentElement.style.setProperty("--accent", "red")`.

Что выносить в переменные: цвета, шрифты, радиусы скругления, основные отступы. Получается мини-дизайн-система.

### Пример
```css
:root {
  --bg: #ffffff;
  --text: #1e2a36;
  --muted: #5b6875;
  --accent: #1f4fd8;
  --radius: 12px;
  --space: 16px;
}

body {
  background: var(--bg);
  color: var(--text);
}

.btn {
  background: var(--accent);
  border-radius: var(--radius);
  padding: calc(var(--space) * 0.75) var(--space);
}

.promo {
  --accent: #e8590c;   /* внутри промо-блока кнопки будут оранжевыми */
}
```

### Частые ошибки
- Писать с одним дефисом: `-accent` — не сработает.
- Забыть `var()`: `color: --accent` — не сработает.
- Плодить по переменной на каждый оттенок «на всякий случай». Начни с 5–8 основных.

### Мини-задание
Вынеси все цвета своей страницы в переменные в `:root`. Затем поменяй `--accent` в одном месте и проверь, что поменялись все кнопки и ссылки.

### На пальцах
`transition` — плавное закрывание двери с доводчиком вместо хлопка: из состояния А в состояние Б не мгновенно, а за 0,2 секунды. `transform` — подвинуть, повернуть или увеличить предмет, не двигая мебель вокруг. `@keyframes` — мультфильм по кадрам. `prefers-reduced-motion` — уважение к тем, кого от анимации укачивает.

### Как это работает
- `transition: свойство длительность функция` — анимирует изменение, например при `:hover`.
- `transform: translateY(-4px) scale(1.02) rotate(5deg)` — сдвиг, масштаб, поворот. Соседи не сдвигаются, браузер рисует это быстро.
- Анимировать дешевле всего `transform` и `opacity`. Анимация `width`, `top`, `margin` заставляет браузер пересчитывать раскладку и может тормозить.
- `@keyframes имя { from {...} to {...} }` + `animation: имя 1s ease infinite` — самостоятельная анимация.
- `@media (prefers-reduced-motion: reduce)` — у пользователя в системе включено «уменьшить движение». Убери или упрости анимации.

### Пример
```css
.card {
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}
.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgb(0 0 0 / 12%);
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.08); }
}
.badge-new {
  animation: pulse 1.5s ease-in-out infinite;
}

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

### Частые ошибки
- `transition: all` — анимируется всё подряд, включая то, что не нужно.
- Слишком долгие анимации: 1–2 секунды на наведение раздражают. Ориентир — 150–300 мс.
- Писать `transition` только в `:hover` — тогда анимация будет только «туда», а обратно — рывком. Пиши её в основном правиле.

### Мини-задание
Сделай карточкам плавный подъём при наведении, кнопке — плавную смену цвета, значку «Новинка» — пульсацию. Включи в системе «уменьшение движения» (или эмулируй в DevTools → Rendering) и проверь, что анимации отключились.

### На пальцах
`clamp()` — резинка с ограничителями. Заголовок растягивается вместе с экраном, но не меньше «маленького» размера и не больше «большого». На телефоне не огромный, на мониторе не крошечный — и никаких медиазапросов.

### Как это работает
`clamp(минимум, желаемое, максимум)`:

- **минимум** — меньше этого не будет, например `28px` на маленьком телефоне;
- **желаемое** — значение, зависящее от ширины экрана, например `5vw` (5% ширины окна);
- **максимум** — больше этого не будет, например `56px`.

Чтобы шрифт оставался масштабируемым при увеличении в браузере, к `vw` добавляют `rem`: `clamp(1.75rem, 1rem + 3vw, 3.5rem)`.

`clamp()` работает не только для шрифтов: для отступов секций, ширины колонок, внутренних полей.

Похожие функции: `min(a, b)` — меньшее из двух, `max(a, b)` — большее.

### Пример
```css
h1 {
  font-size: clamp(1.75rem, 1rem + 3vw, 3.5rem);   /* 28px … 56px */
  line-height: 1.1;
}

h2 {
  font-size: clamp(1.4rem, 1rem + 1.5vw, 2.25rem);
}

.section {
  padding-block: clamp(40px, 8vw, 120px);
}

.container {
  width: min(100% - 32px, 1200px);
  margin-inline: auto;
}
```

### Частые ошибки
- Только `vw` без ограничений: на телефоне заголовок 12px, на 4K-мониторе — 150px.
- Минимум больше максимума.
- Чистые `vw` без `rem` — шрифт перестаёт реагировать на зум и настройки пользователя.

### Мини-задание
Сделай резиновые размеры для `h1`, `h2` и отступов секций через `clamp`. Проверь ширины 375 и 1440px — заголовки должны выглядеть пропорционально на обоих.

### На пальцах
БЭМ — система подписей для коробок при переезде. Блок — «Кухня». Элемент — «Кухня: тарелки». Модификатор — «Кухня: тарелки, хрупкое». По подписи сразу понятно, что это, к чему относится и чем особенное. И никто не перепутает тарелки с кухни и тарелки с дачи.

### Как это работает
- **Блок** — самостоятельный компонент: `.card`, `.menu`, `.btn`.
- **Элемент** — часть блока, через два подчёркивания: `.card__title`, `.card__photo`, `.menu__link`.
- **Модификатор** — вариант или состояние, через два дефиса: `.btn--primary`, `.card--featured`, `.menu__link--active`.

Правила:

- Элемент принадлежит только своему блоку и вне его не используется.
- Не делай «внуков»: `.card__body__title` — плохо, `.card__title` — хорошо, даже если заголовок глубоко вложен.
- Модификатор добавляется к основному классу: `class="btn btn--primary"`.
- Стили пишем по одному классу, без вложенных селекторов вроде `.card h3`. Так у всех селекторов одинаковый вес и никаких войн специфичности.

### Пример
```html
<article class="card card--featured">
  <img class="card__photo" src="img/landing.jpg" alt="Пример лендинга">
  <h3 class="card__title">Лендинг под ключ</h3>
  <p class="card__price">от 30 000 ₽</p>
  <a class="btn btn--primary" href="#order">Заказать</a>
</article>
```

```css
.card { padding: 20px; border-radius: 12px; background: #fff; }
.card--featured { border: 2px solid #1f4fd8; }
.card__title { margin: 12px 0 4px; }
.card__price { font-weight: 700; }

.btn { padding: 12px 20px; border-radius: 10px; }
.btn--primary { background: #1f4fd8; color: #fff; }
```

### Частые ошибки
- `.card__body__title` — цепочки элементов.
- Модификатор без основного класса: `class="btn--primary"`.
- Смешивать БЭМ и селекторы по тегам внутри блоков.

### Мини-задание
Перепиши классы своих карточек и кнопок по БЭМ. Сделай вариант «рекомендуем» через модификатор `card--featured`.

### На пальцах
Многие ставят на телефон и компьютер тёмную тему, особенно вечером. `prefers-color-scheme` — сайт спрашивает систему: «Хозяин любит тёмное?» — и сам переодевается. А благодаря переменным переодеться — значит поменять пять банок краски, а не перекрашивать каждую стену.

### Как это работает
1. Все цвета — в переменных в `:root`.
2. В медиазапросе `@media (prefers-color-scheme: dark)` переопределяешь только переменные.
3. `color-scheme: light dark` подсказывает браузеру перекрасить полосы прокрутки, поля ввода и прочие системные элементы.

Чтобы дать переключатель вручную, используют атрибут на `html`: `data-theme="dark"`, и JavaScript, который его ставит и запоминает выбор в `localStorage`.

Тёмная тема — это не инверсия. Чистый чёрный `#000` и чистый белый текст режут глаза; лучше тёмно-серый фон и светло-серый текст. Акцентные цвета в тёмной теме делают чуть светлее и менее насыщенными.

### Пример
```css
:root {
  color-scheme: light dark;
  --bg: #ffffff;
  --surface: #f3f5f8;
  --text: #16202a;
  --accent: #1f4fd8;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #0f151b;
    --surface: #17202a;
    --text: #e6ecf1;
    --accent: #86a6ff;
  }
}

body { background: var(--bg); color: var(--text); }
.card { background: var(--surface); }
```

Проверить без смены настроек системы: DevTools → Ctrl + Shift + P → «Emulate CSS prefers-color-scheme: dark».

### Частые ошибки
- Цвета вписаны прямо в правила, а не в переменные — тёмную тему придётся писать заново.
- Забыть про картинки и логотипы: тёмный логотип исчезает на тёмном фоне.
- Низкий контраст серого текста на тёмно-сером фоне.

### Мини-задание
Добавь своему лендингу тёмную тему через `prefers-color-scheme`. Проверь эмуляцией в DevTools, что все тексты читаются, а логотип и иконки видны.

### На пальцах
GitHub Pages — бесплатная витрина для твоего проекта. Код уже лежит на GitHub, как товар на складе. Pages выставляет его на витрину по адресу `твой-логин.github.io/проект`, и любой может открыть сайт по ссылке. Идеально для портфолио.

### Как это работает
1. Сайт — статические файлы: HTML, CSS, JS, картинки. Главная страница должна называться `index.html`.
2. Отправь проект на GitHub (`git push`).
3. На странице репозитория: Settings → Pages.
4. В разделе «Build and deployment» выбери Source: «Deploy from a branch», ветку `main` и папку `/ (root)`. Нажми Save.
5. Через минуту-две сайт будет доступен по адресу `https://логин.github.io/имя-репозитория/`.
6. Каждый новый `git push` обновляет сайт автоматически.

Особенность: сайт живёт не в корне домена, а в подпапке `/имя-репозитория/`. Поэтому пути, начинающиеся с `/` (`/img/logo.png`), сломаются. Используй относительные пути: `img/logo.png`.

Можно подключить свой домен: Settings → Pages → Custom domain, плюс запись в DNS у регистратора.

### Пример
```text
web-landing/
├── index.html
├── css/style.css
└── img/hero.jpg
```

```bash
git add .
git commit -m "feat: готов первый лендинг"
git push
# Settings → Pages → Branch: main / root → Save
# https://anna.github.io/web-landing/
```

### Частые ошибки
- Главный файл называется `Index.html` или `home.html` — Pages покажет 404.
- Абсолютные пути `/css/style.css` — стили не загрузятся.
- Разный регистр в именах файлов и ссылках: на GitHub Pages `Hero.JPG` и `hero.jpg` — разные файлы.

### Мини-задание
Опубликуй свой первый лендинг на GitHub Pages. Открой ссылку с телефона и отправь её кому-нибудь из знакомых. Добавь ссылку на сайт в описание репозитория (шестерёнка «About» справа).
