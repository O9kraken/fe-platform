Словарь разработчика

Слова, которые говорят в командах и спрашивают на собеседованиях: что это простыми словами, пример из жизни и, где нужно, готовый ответ для интервью.

Как учиться, чтобы не бросить

Пять коротких занятий в неделю лучше одного марафона в воскресенье. Мозг запоминает то, к чему возвращается, а не то, что долго читал.

Часть занятияДоляЧто делаешь
Теория20–30%Читаешь тему недели, жмёшь «Разобрать» у непонятного пункта, выписываешь термины своими словами.
Практика50–60%Решаешь задачи в редакторе, пока все тесты не станут зелёными. Потом меняешь условие сам и ломаешь код нарочно.
Повторение10–20%Через пару дней решаешь задачу ещё раз с нуля. Или генерируешь похожую.

Как пользоваться платформой

  • Каждый день открывай «Маршрут» на текущей неделе и закрывай хотя бы один пункт. Так растёт серия дней.
  • Задачи решай сначала сам. Подсказки открываются по одной, эталон — после трёх попыток.
  • Когда встроенные задачи недели закончились, жми «Сгенерировать задачу».
  • Любой код из объяснений можно открыть в песочнице кнопкой «В песочницу».
  • Ctrl + Enter в редакторе — запустить, Ctrl + / — закомментировать строку.

Правила

  • Не вставляй код, который не можешь объяснить построчно.
  • Ошибка — подсказка. Прочитай сообщение в консоли, найди строку, проверяй гипотезы по одной.
  • Наставник объясняет и подсказывает, но не пишет решение за тебя.
  • Один стек: HTML/CSS → JS → TS → React → Next.js.
  • Застрял — задержись на неделе. Отставание от календаря не провал.

Что установить к неделе 2

  • Chrome или Firefox с DevTools
  • VS Code + Prettier, ESLint
  • Git и аккаунт GitHub, Node.js LTS
  • Для бэкенда: бесплатная база в Neon, Docker Desktop, Bruno или Postman для запросов

Готов к работе?

Отмечай честно. Когда закрыто 9 из 10 — начинай откликаться, не дожидаясь идеала.
